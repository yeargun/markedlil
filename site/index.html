Parse-only official 18.0.10 sources, then Oxc and Terser with mangling enabled and disabled. @itslil/marked is the LilScript compiler output. It is not post-minified. The full npm file is listed last as a diagnostic.

Lane Raw gzip-9 Brotli-11 Brotli size vs Oxc

Why parse-only. LilScript cannot override methods, so this port has no use() / Hooks / walkTokens. The published npm file still includes that ABI. The fair fight is the 18.0.10 parse path, then the same Oxc and Terser work the JS ecosystem actually ships. The published LilScript artifact is still the compiler-selected module.
